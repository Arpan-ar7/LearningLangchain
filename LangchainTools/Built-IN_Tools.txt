2. 🌐 Web / HTTP tools

These are extremely useful for agents.

Tool	Use case	Install
Requests GET	Call an API	uv add requests
Requests POST	Send data to API	uv add requests
Requests PUT	Update API resource	uv add requests
Requests PATCH	Partially update API resource	uv add requests
Requests DELETE	Delete API resource	uv add requests

LangChain's Requests tools provide GET, POST, PUT, PATCH and DELETE operations.

Install:

uv add requests

4. 🗄️ SQL / Database tools

These are VERY important for ML/AI engineering jobs.

Tool	Use case
QuerySQLDatabaseTool	Execute SQL
InfoSQLDatabaseTool	Get database schema
ListSQLDatabaseTool	List tables
QuerySQLCheckerTool	Check generated SQL
SQLDatabaseToolkit	Collection of SQL tools

LangChain provides SQL tools for querying databases, inspecting schemas and checking generated SQL.

Install the relevant database driver depending on your DB.

For SQLite:

uv add sqlalchemy

For PostgreSQL:

uv add sqlalchemy psycopg2-binary

This lets you build:

User:
"How many users registered this month?"

        ↓

AI Agent

        ↓

SQL Tool

        ↓

SELECT COUNT(*) ...

        ↓

Database

        ↓

Answer

Definitely learn this one.

6. 🐙 GitHub tools

The GitHub integration allows an agent to interact with GitHub repositories.

Use cases:

"Find the README"
"Search this repository"
"Inspect this code"
"Create/update GitHub actions"

The GitHub tool uses the PyGithub library and requires GITHUB_API_TOKEN and repository information.

Install:

uv add PyGithub
